Qué hacemos

Dos disciplinas, una sola visión.

Cada proyecto puede arrancar por cualquiera de los dos frentes, o por ambos. La coherencia entre lo que se ve y cómo funciona es lo que nos diferencia.

01 Diseño Gráfico

Identidad y piezas con criterio.

Partimos de la estrategia de marca y terminamos en archivos listos para producir: una identidad consistente que funciona en pantalla, en impresión y en redes.

Entregables principales

  • Identidad visual y branding: logo, paleta, tipografía y manual
  • Piezas editoriales y publicitarias
  • Empaques y artes finales listos para imprenta
  • Dirección de arte y contenido para redes (carruseles, portadas, plantillas)

Herramientas clave

  • Illustrator
  • Photoshop
  • InDesign
  • Figma

02 Desarrollo Web

Sitios rápidos, a medida.

Construimos con tecnología simple y sólida: HTML semántico, CSS moderno y JavaScript justo. Menos peso, mejor posicionamiento y mantenimiento sin dolores de cabeza.

Entregables principales

  • Sitios web a medida y landing pages
  • E-commerce y catálogos
  • Aplicaciones web ligeras
  • Rendimiento (Core Web Vitals) y SEO técnico

Stack clave

  • HTML5
  • Tailwind CSS
  • JavaScript
  • GSAP
  • Hosting estático
